## 유지해야 할 작업 원칙

- 원본 Weetory의 비AI 메뉴와 상세 업무 흐름을 참조한다. AI 생성·음성 인식 기능은 제외한다.
- 현재 단계는 화면 PoC다. 로컬 DB 연결은 후속 단계이며, 현재 화면의 변경 내용은 앱 종료 시 초기화된다.
- UI는 밝은 파란색·흰색 분위기의 shadcn/ui + Radix UI + Tailwind CSS로 유지한다.
- 브랜드 교체 대상은 **화면 내부 로고**다. 실행 파일·Dock·설치 프로그램의 앱 아이콘은 교체 대상이 아니다.
- 기능별로 커밋한다. Conventional Commits prefix 뒤 제목·본문은 한국어로 작성한다.
- **사용자가 다시 요청하기 전까지 develop에 머지하지 않는다.** 초기 머지 요청보다 이후의 머지 금지 지시를 우선한다.
- 이 작업 환경에서는 `rg`를 실행하지 않는다. 파일·본문 탐색은 `find`, `grep`, Python 등을 사용한다.
