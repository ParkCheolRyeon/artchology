### 간격 수정은 여러 차례 보완

사용자 스크린샷을 통해 아래 문제를 순차적으로 발견했다.

1. 새 사례 등록의 제목·검색창·학생 선택 카드가 붙어 있었다.
2. 상담 입력 textarea 아래에 다음 항목 라벨이 붙어 있었다.
3. 보고서의 선택 건수와 미리보기 버튼에 간격 규칙이 없었다.
4. 최근 기록이 `space-between`으로 배치되어 텍스트 길이에 따라 날짜·이름·제목의 열 위치가 달라졌다.
5. 섹션 간격을 수정한 뒤에도 중첩된 `fieldset` 안의 나이스 상담제목·내용은 여전히 붙어 있었다.

## 7. 절제된 인터랙션 애니메이션

사용자는 사이드바를 포함해 적절한 곳에 과하지 않은 움직임을 요청했다.

- 사이드바: 220ms grid 열 너비 전환과 내용의 clip·opacity 전환.
- 화면 전환: 160ms opacity 전환. 애니메이션을 위해 화면을 강제로 재마운트하지 않음.
- 버튼·메뉴·탭·목록: 약 150ms 색상·테두리 변화.
- 활동 카드: 180ms, 최대 2px 위로 이동.
- 모달·드롭다운·팝오버·상태 알림: 짧은 전환.
- 접힌 사이드바는 `inert`와 `aria-hidden`으로 포커스·접근성 처리.
- `prefers-reduced-motion` 설정 대응.

관련 커밋: `483da14`.

## 8. 탭 indicator 이동

추가 요청으로 탭 내부 선택 표시에도 움직임을 적용했다.

- 하위 메뉴와 상단 열린 화면 탭에 공통 `TabIndicator` 적용.
- 선택된 탭의 위치·너비·높이를 측정해 200ms 동안 이동.
- 글자 길이, 탭 추가·닫기, 컨테이너 크기 변경에 대응.
- ResizeObserver·MutationObserver로 상태와 크기 변화를 추적하고 언마운트 시 해제.
- 키보드 탭 전환과 동작 줄이기 설정 대응.
