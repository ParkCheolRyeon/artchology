# 검증과 실행

기록일: 2026-10-28.

## 실행 환경과 명령

Node.js 22.12 이상, pnpm 10.33.0을 사용한다. 개발 환경의 기본 Node가 20인 경우 Node 22를 선택한 뒤 실행한다.

```sh
pnpm install
pnpm dev
pnpm lint
pnpm build
pnpm test
pnpm build:unpack
```

- `pnpm build`: TypeScript 검사 후 electron-vite 빌드.
- `pnpm test`: 최신 빌드 생성 후 Playwright 테스트. 소스 수정 후 이전 `out/`을 직접 테스트하지 않도록 한다.
- `pnpm build:unpack`: 빌드 후 설치하지 않고 실행 가능한 앱 생성.
- Apple Silicon 결과물: `dist/mac-arm64/artchology.app`.
- Windows 빌드 명령: `pnpm build:win`. Windows 실행 검증은 별도다.
- 현재 macOS 패키징은 코드 서명·공증을 하지 않는 개발용 구성이다.

## 최신 자동 검증 결과

이 세션에서 타입 검사·빌드·lint를 통과했고, 탭 indicator 검증까지 포함한 **7개 테스트가 모두 통과**했다. 이후 실행용 macOS 앱을 패키징했다.

| 테스트                          | 확인 범위                                                                              |
| ------------------------------- | -------------------------------------------------------------------------------------- |
| 원본 메뉴와 모든 하위 화면 탐색 | 주요 메뉴·하위 경로, 화면 오류, 사이드바 접기·펼치기, 접힌 메뉴 접근 제한, 동작 줄이기 |
| 종일·여러 날 일정               | 일정 등록·편집·삭제, 월·주·일·목록 보기                                                |
| 실제 일정 드래그                | 마우스 이동, 기간 조정, 되돌리기                                                       |
| 학생→사례→상담 연결             | 학생 등록에서 상담 작성, 캘린더 표시까지                                               |
| 공통 UI                         | 드롭다운 키보드·포커스, 날짜 선택·잘못된 날짜 검증, 모달 내부 팝업, 화면 폭            |
| 마음 그리기                     | 홈 카드 진입, 실제 캔버스 픽셀 변화, 되돌리기, 지우기 취소, 저장·작품 재열기           |
| 탭 선택 표시                    | 위치·너비 정렬, 키보드 이동, 창 크기 변경, 상단 화면 탭 전환, 동작 줄이기              |

테스트는 임시 사용자 디렉터리와 `ARTCHOLOGY_TEST_HEADLESS=1` 환경의 숨김 Electron 창을 사용한다. 일반 사용자의 작업 데이터를 검증용으로 덮어쓰지 않는다.

## 별도 화면·측정 확인

- 사례 등록: 제목과 첫 입력 그룹, 검색창과 학생 카드, 하단 동작 간격.
- 상담 정보: 연속 textarea 사이의 라벨 간격.
- 보고서: 필터·워크시트·선택 건수·미리보기 버튼 배치.
- 학생 등록 모달: 기본 정보·학적 그룹과 하단 버튼 영역.
- 나이스 상담제목·내용: 중첩 fieldset의 항목 간격을 실제 화면에서 24px로 측정.
- 최근 기록: 1440px·980px 창에서 각 행의 열 시작 위치 일치 확인.
- 주요 메뉴를 순회하며 세로로 인접한 Field의 간격이 16px 미만인 경우를 탐지하는 임시 점검을 실행했고, 해당 조건의 잔여 문제는 없었다.
- 마음 그리기 활동 목록·캔버스·작품 보관함과 탭 indicator 화면 캡처 확인.

임시 측정 스크립트는 `/private/tmp/artchology-spacing.cjs`에서 실행했다. 이 파일은 저장소에 포함된 영구 테스트가 아니다. 유지·재현이 필요한 핵심 동작은 `tests/desktop.spec.ts`를 기준으로 확인한다.

스크린샷과 실패 trace는 `test-results/`에 생성되며 Git에서 제외된다. 재실행하면 이전 결과가 덮어써질 수 있다. 캡처 시에는 `animations: 'disabled'`를 사용해 팝업 전환 중간 프레임을 피한다.

## 검증 과정에서 보완한 점

- 이전 빌드의 `out/`을 실행하면 새 기능이 없는 것으로 실패할 수 있다. 최신 빌드 완료를 확인한 후 테스트한다.
- 캔버스 테스트는 학생 선택 팝업이 완전히 닫힌 뒤 캔버스를 화면 안으로 이동하고 그린다. 닫히는 팝업이 포인터를 가로채면 그림 검증이 잘못 실패할 수 있다.
- 숫자 배지가 있는 사이드바 메뉴는 접근성 이름과 `textContent`가 다를 수 있어 탐색 선택자를 조정했다.

## 검증 한계

- 메뉴 탐색 통과가 모든 입력 조합·예외·원본 상태의 동일성을 보장하지 않는다.
- 화면 간격 자동 측정은 특정 DOM 구조의 인접 필드에 대한 점검이다. 모든 시각적 품질을 자동 판정한 것은 아니다.
- 실제 서버·발송·결제·암호화·AI·영속 DB 동작은 이번 검증 대상이 아니다.
- macOS Apple Silicon에서 확인했으며 Windows·다른 화면 배율·보조공학 도구의 전면 검증은 남아 있다.
- 동작 줄이기와 키보드 포커스 일부를 검증했지만 전체 접근성 인증을 뜻하지 않는다.

## 다음 변경 시 확인할 것

- 메뉴·상세 화면을 추가할 때 현재 `weetory` 진입 구조에 연결했는지 확인한다. 이전 `pages` 코드만 수정하면 실제 앱에 나타나지 않을 수 있다.
- 입력 UI 변경 시 섹션뿐 아니라 중첩 fieldset, 모달, 읽기 전용 상세를 확인한다.
- 애니메이션 변경 시 포커스, 팝업 닫힘, 드래그 좌표, 축소 모션을 함께 확인한다.
- 커밋 직전에 현재 브랜치를 확인한다. 사용자 승인 없이 develop으로 병합하거나 해당 브랜치에 작업 커밋을 남기지 않는다.
